# Criação de Documentos Científicos com HTML/CSS/JS

A estrutura básica de um arquivo html é iniciada por `<html></html>` que dentro possui uma estrutura de cabeçalho iniciada por `<head></head>` e uma estrutura para o corpo do texto delimitada por `<body></body>`.

Dentro de body podemos ter paragrafos `<p><\p>`, tabelas `<table><\table>`, conteiners `<div><\div>`.
